# Roadmap

1. **Fundação — entregue para revisão:** arquitetura SPA, Tailwind, tokens, fontes, páginas mínimas, i18n, lint, testes, CI, documentação e ícone do 404 com `@lucide/vue`.
2. **Interface e conteúdo — próximo:** aprovar wireframes e textos, então implementar o layout e as seções finais.
3. **Projetos e efeitos — posterior:** publicar só os estudos de caso aprovados, validar slugs de projetos e definir o orçamento de performance. Prototipar o Digital Core com alternativa estática; avaliar GSAP ou Three.js somente se o efeito justificar.
4. **Pré-publicação — posterior:** implementar SEO e pré-renderização, validar acessibilidade e performance em múltiplos ambientes, revisar host e configurar a Vercel após autorização.
