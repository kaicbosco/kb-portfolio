# Roadmap

1. **Fundação — entregue para revisão:** arquitetura SPA, Tailwind, tokens, fontes, páginas mínimas, i18n, lint, testes, CI, documentação e ícone do 404 com `@lucide/vue`.
2. **Conteinerização (Handoff 002.1) — entregue para revisão:** Docker opcional, Nginx não privilegiado, quality gate e fluxo GHCR configurado. A CI remota, a publicação e o deploy não foram executados no handoff.
3. **Crimson Void Design System (Handoff 003) — implementado, aguardando revisão humana:** tokens semânticos, primitivos, hierarquia, Bento Grid e playground exclusivo de desenvolvimento. A homepage e as seções definitivas permanecem fora desta entrega.
4. **Application Shell (Handoff 004) — próximo, após revisão:** reutilizar a fundação visual para estruturar a navegação e os landmarks. Aprovar wireframes e textos antes das seções definitivas.
5. **Projetos e efeitos — posterior:** publicar só os estudos de caso aprovados, validar slugs de projetos e definir o orçamento de performance. Prototipar o Digital Core com alternativa estática; avaliar GSAP ou Three.js somente se o efeito justificar.
6. **Pré-publicação — posterior:** implementar SEO e pré-renderização, validar acessibilidade e performance em múltiplos ambientes, revisar host e configurar a Vercel após autorização.
