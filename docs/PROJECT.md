# Projeto

KB. Portfolio apresenta a experiência, as competências, os projetos e a formação de Kaíque Bosco, desenvolvedor front-end e estudante de Engenharia de Software. Tem dois objetivos: apoiar candidaturas para estágio e desenvolvimento júnior no Brasil e no exterior, e demonstrar a qualidade do código front-end.

## Plataforma

- Vue 3, TypeScript, Vite, Tailwind CSS 4, Vue Router e Vue I18n.
- Lucide Vue para ícones e Fontsource para fontes hospedadas junto ao site.
- pnpm, Git, Prettier, Oxlint, Vitest, Vue Test Utils, Playwright e GitHub Actions.
- Vercel é o destino planejado, sem deploy ou configuração de produção neste handoff.

## Limites da entrega

A fundação estabeleceu arquitetura, manutenção, testes e páginas mínimas. A homepage já tem o Hero bilíngue, o Digital Core e o Bento Strip. Consulte o [roadmap](ROADMAP.md) para o escopo dos estudos de caso e das demais seções.
